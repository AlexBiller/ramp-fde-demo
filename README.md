# Policy Review Agent — unofficial Ramp FDE demo

> **Unofficial demo built with Devin - synthetic data.** Not affiliated with or endorsed by Ramp. Every person, company, merchant and transaction here is fictional and generated by a seed script.

**Live demo:** https://raw.githack.com/AlexBiller/ramp-fde-demo/gh-pages/index.html
(static files from the `gh-pages` branch, served through the free public githack CDN)

A small prototype of the kind of agent a Forward Deployed Engineer might build with a finance team: it reviews corporate-card transactions against an expense policy, explains every decision with citations back to the source records, and is measured on a labeled evaluation set before anyone trusts it.

## What you can do (≈5 minutes)

1. **Review** — pick a seeded transaction and run the agent. It returns *Approve / Flag / Reject*, a confidence score, and step-by-step reasoning.
2. **Trace** — every step cites the policy clause and the exact records/fields it used (transaction, receipt, trip, vendor list, employee). Click a chip to open the record with the used fields highlighted.
3. **Evaluate** — run the 47-case labeled set and see accuracy, violation recall/precision, false-flag rate, a confusion matrix and per-case misses.
4. **Compare** — configure two agents side by side (memo reading, trip context, vendor list, duplicate scan, over-cap tolerance) and inspect every case where they disagree, with both traces next to each other.

Suggested walkthrough: on **Review**, select *Team dinner after release* and run it with *Baseline* and then *Context-aware*. On **Compare**, set B to *Context-aware + 5% tolerance* to see the recall/false-flag trade-off.

## How it works

- `seed/seed.py` — deterministic generator (fixed RNG seed) for the fictional company *Fernwood Robotics*: employees, merchants, an 8-clause expense policy, approved vendors, trips, receipts, 47 transactions and the ground-truth labels with reviewer notes. Writes `data/seed.json` and `data/seed.js`.
- `app/agent.js` — the agent: a deterministic, explainable reasoning pipeline (classify → read memo → apply policy clauses → check trip / vendor / duplicate context → decide). It calls **no** external model or API, so it is free, reproducible and runs fully in the browser.
- `app/app.js`, `app/styles.css`, `index.html` — static single-page UI (no build step, no backend, no login, no tracking).
- `tests/agent.test.mjs` — checks data integrity, that every citation resolves to a real record field, eval expectations, and that the disclaimer banner is on every page.

## Run locally

Requirements: Python 3 (and Node 18+ only for tests).

```bash
python3 seed/seed.py               # regenerate synthetic data (optional; output is committed)
python3 -m http.server 8000        # then open http://localhost:8000
node --test tests/agent.test.mjs   # run tests
```

Opening `index.html` directly from disk also works.

## Deployment

`.github/workflows/pages.yml` runs on every push to `main`: it regenerates the seed data (and fails if the committed data is stale), runs the tests, and publishes the static site to the `gh-pages` branch. That branch is served publicly via githack. The site is plain static files, so it can also be served with GitHub Pages (Settings → Pages → Deploy from branch → `gh-pages`) or any static host.

## Data & credentials

- Synthetic, seeded data only. No real customer data, no real credentials, no login.
- The demo does not call or access any Ramp system or API. Public information about Ramp (an open FDE job posting) was used as background only.
